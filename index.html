Хочешь, чтобы я рассказывал сам, по-дружески? Добавь API-ключ Claude в настройках (шестерёнка сверху). Без ключа будет справка из Википедии и кнопка «Спросить Claude», которая откроет приложение Claude с готовым вопросом.

Настройки

Ключ хранится только в этом браузере и уходит напрямую в api.anthropic.com. Взять можно на console.anthropic.com → API Keys. Рассказ стоит примерно цент-два.
